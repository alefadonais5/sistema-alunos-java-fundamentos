# Sistema de Alunos — Java Fundamentos

Sistema desenvolvido em Java para praticar os fundamentos da linguagem.

## Tecnologias

- Java

## Conceitos praticados

- Sintaxe básica
- Variáveis e tipos de dados
- Operadores
- if / else
- switch
- for
- while
- do while
- String
- Arrays
- Métodos
- Scanner
- Boolean
- Entrada de dados pelo usuário

## Funcionalidades

- Cadastro do nome do aluno
- Cadastro da idade
- Cadastro de 3 notas
- Cálculo da soma das notas
- Cálculo da média
- Verificação de aprovação
- Exibição da situação do aluno

## Objetivo

Projeto desenvolvido como parte dos estudos de Java, com foco na consolidação dos fundamentos da linguagem.
